# Deployment: sent Draft refresh, 1.8.19

Release **1.8.19** was installed on the n0c production instance on 2026-09-19.
After an edited unread Draft is sent, its reminder now disappears as soon as the
server confirms the send instead of sometimes remaining visible until the next
minute poll.

## Cause and correction

Closing the composer schedules an unread-Drafts refresh while background Undo Send
is still saving its durable copy. That early request can snapshot the original unread
Draft before the save replaces it and before the send removes the replacement. Its
late response then redraws a Draft that no longer exists.

`unread-drafts.js` now treats `pw-message-sent` as the authoritative later edge. It
invalidates any in-flight Drafts response, clears its rendered reminder state and
queries the current Drafts folder again. No SMTP, IMAP mutation or message-building
contract changed.

